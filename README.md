# 2026–27 다이어리

ADHD를 위한 2026년 10월–2027년 9월 다이어리 웹앱입니다.

- 아이폰, 아이패드, 노트북에서 같은 내용이 보여요. 구글 계정으로 로그인하면 동기화돼요.
- 구글 캘린더 일정이 달력에 자동으로 표시돼요.
- 홈 화면에 추가하면 앱처럼 전체 화면으로 열려요.
- 한 번 열어 둔 기기에서는 인터넷이 끊겨도 열려요.

처음 한 번만 아래 순서대로 설정하면 됩니다. 30분 정도 걸려요.

---

## 1. 깃허브에 올리고 주소 만들기

1. GitHub에서 새 저장소를 만들어요. 예: `diary`
   - 공개(Public)여야 무료로 GitHub Pages를 쓸 수 있어요.
   - 다이어리 내용은 저장소가 아니라 Firebase에 저장되니 공개해도 괜찮아요.
2. 이 폴더의 파일을 전부 올려요.
3. 저장소의 **Settings → Pages**로 가서 아래처럼 정하고 저장해요.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더는 **/(root)**
4. 1~2분 뒤 주소가 생겨요: `https://내아이디.github.io/diary/`

이 단계만 끝내도 다이어리는 열려요. 다만 아직 '설정 전'이라 기기마다 따로 저장돼요.

## 2. Firebase 프로젝트 만들기 (동기화용, 무료)

1. https://console.firebase.google.com 에서 **프로젝트 추가**를 눌러요.
   - 이름 예: `my-diary`
   - Google 애널리틱스는 꺼도 돼요.
2. 프로젝트 첫 화면에서 웹 아이콘 **`</>`**를 눌러 웹 앱을 추가해요.
   - 앱 이름 예: `diary`
   - Hosting 체크는 하지 않아요.
3. 화면에 나오는 `firebaseConfig` 값(apiKey, authDomain 등 6개)을 이 폴더의 **firebase-config.js**에 그대로 옮겨 적고, 깃허브에 다시 올려요.

## 3. 구글 로그인 켜기

1. Firebase 왼쪽 메뉴에서 **Authentication → 시작하기**를 눌러요.
2. **Sign-in method → Google**을 선택해 **사용 설정**하고, 지원 이메일에 본인 Gmail을 골라 저장해요.
3. **Settings → 승인된 도메인 → 도메인 추가**에 `내아이디.github.io`를 넣어요.

## 4. 저장소(Firestore) 만들기

1. 왼쪽 메뉴에서 **Firestore Database → 데이터베이스 만들기**를 눌러요.
   - 위치: **asia-northeast3 (서울)**
   - 시작 모드: **프로덕션 모드**
2. **규칙** 탭에 이 폴더의 **firestore.rules** 내용을 붙여 넣고 **게시**해요.
   - 로그인한 본인만 자기 다이어리를 읽고 쓸 수 있게 막는 규칙이에요.

## 5. 구글 캘린더 읽기 허용

1. https://console.cloud.google.com 에 들어가 위쪽 프로젝트 선택에서 2단계에서 만든 Firebase 프로젝트를 골라요.
2. **API 및 서비스 → 라이브러리**에서 **Google Calendar API**를 찾아 **사용**을 눌러요.
3. **API 및 서비스 → OAuth 동의 화면**(또는 **Google 인증 플랫폼**)으로 가요.
   - **대상(테스트 사용자)**에 본인 Gmail을 추가해요.
   - **데이터 액세스(범위)**에 `.../auth/calendar.readonly`를 추가해요.
   - 게시 상태는 **테스트**로 두면 돼요. 본인만 쓰는 앱이라 구글 심사가 필요 없어요.

## 6. 기기마다 설치하기

- **아이폰·아이패드**
  1. Safari로 다이어리 주소를 열어요.
  2. 공유 버튼 → **홈 화면에 추가**를 눌러요.
  3. 홈 화면 아이콘으로 열어요.
  4. 아래 막대의 **로그인**을 눌러 구글 계정을 골라요.
- **노트북 크롬**
  1. 주소를 열어요.
  2. 주소창 오른쪽의 **설치** 아이콘을 누르면 앱 창으로 열려요. 즐겨찾기(⌘+D)만 해 둬도 돼요.
  3. **로그인**을 눌러요.

세 기기 모두 같은 구글 계정으로 로그인하면 동기화돼요. 아래 막대에 **동기화됨**(초록 점)이 보이면 정상이에요.

---

## 알아 두기

- **구글 캘린더 새로고침**
  - 구글이 내주는 캘린더 열쇠는 1시간마다 만료돼요.
  - 만료되면 막대에 **캘린더 새로고침**이 떠요. 한 번 누르면 바로 다시 불러와요.
  - 그사이에도 마지막으로 불러온 일정은 계속 보여요.
- **아이폰 홈 화면 앱에서 로그인 창이 안 열릴 때**
  - Safari에서 같은 주소를 열어 로그인하고 쓰면 돼요.
  - 아이폰은 홈 화면 앱과 Safari의 저장 공간이 따로라 생길 수 있는 문제예요.
- **로그아웃:** 막대의 **동기화됨**을 두 번 연달아 누르면 로그아웃돼요. 그 기기에 쓴 내용은 남아요.
- **비밀 메모:** 기기에서 암호화한 다음 올라가요. 메모장 비밀번호는 Firebase에도 저장되지 않아요. 잊으면 아무도 열 수 없어요.
- **공휴일:** 음력 공휴일과 대체공휴일은 계산값이에요. 정부 발표와 한 번 대조해 주세요.

| `firestore.rules` | 본인만 읽고 쓰게 하는 규칙 (4단계에서 붙여 넣음) |

| `*.png` | 앱 아이콘 |
